# Frogger Refactor Coursework

This is the base repository for coursework part 3. As discussed in the briefing lecture,
you have two options for turning this into a workable project:

1. Fork this repository, clone it, and rearrange the files in-place into a format Gradle expects, or
2. Download the source files, create a completely separate new Gradle project, and add the files to
   that.

**Please do not do work in this repository directly.**

## Game engine

This project depends on a third-party game engine. The developer didn't document this fact,
which is a very very bad thing and one of the reasons we use build files.

The source for the engine is found at https://github.com/philliplagoc/Game-Engine. You should decide
how to incorporate this code into your project.
